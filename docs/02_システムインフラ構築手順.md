# システムインフラ構築手順書

## ドキュメントの目的
「シールマニア」のインフラ基盤およびWordPressアプリケーション基盤の構築手順を記録したものである。
将来的な横展開や、別ドメインでの同型サイト構築時に、本手順をトレースする際の負荷軽減のために資料を残す。

---

## 1. システムアーキテクチャ概要

| 階層 | 採用技術・サービス |
| --- | --- |
| **インフラ / サーバー** | ConoHa WING（共有サーバー） |
| **ドメイン** | `seal-search.com` |
| **アプリケーション (CMS)** | WordPress |
| **テーマ (UI/UX)** | Cocoon |
| **データベース拡張** | Advanced Custom Fields (ACF) →結局現状使っていない|

### 💡 【補足】コア技術にWordPressを選定した理由
* 前提: 「1人運営（副業）」「トレンド（ブーム）の速さに対応する開発スピード」が必須要件
* WordPress（Webアプリ開発（Next.js / Laravel）を使用しない理由）：フルスクラッチ開発は保守コスト（技術的負債、セキュリティ対応）が高く、初期の立ち上げスピードに劣る。プライグインが充実しているWordPressを選定する。（また、WordPressに、カスタムフィールド（ACF）を組み合わせることで、「裏側はデータベースアプリ、表側はSEOに強いメディア」というハイブリッド構成をノーコード・ローコードで爆速構築できるため。）
* ※将来的に大規模化（月間100万PV、リアルタイムDB同期など）が必要になった段階で、初めてモダンなWebアプリへのリプレイスを検討する。

## 2. インフラ基盤（サーバー・ドメイン）構築手順

### 2-1. ドメインの取得と紐付け

1. ConoHa WINGコントロールパネルにログイン。
2. 左メニュー **[サーバー管理]** > **[ドメイン]** をクリック。
3. 右上 **[＋ドメイン]** > **[新規ドメインを追加]** > **[ドメイン取得]** を選択。
4. 検索バーに `seal-search.com` を入力し、カートに追加して決済を完了する。

---

## 3. アプリケーション（WordPress）インストール手順

### 3-1. WordPressの新規作成
1. 左メニュー **[サイト管理]** をクリック。
2. 左上 **[切り替え]** ボタンから、取得した `seal-search.com` を選択。
3. 右上 **[＋WordPress]** をクリックし、以下情報を入力して **[保存]** をクリック。

| 設定項目 | 入力値（設定値） |
| --- | --- |
| **バージョン** | 最新バージョン（デフォルト） |
| **URL** | `www` なし （例: `seal-search.com`） |
| **サイト名** | シールマニア｜ボンボンドロップ・シールの販売場所・入荷情報まとめ |
| **ユーザー名** | `seal-mania` |
| **パスワード** | `Gongon1121!!` |
| **データベース** | 自動生成（デフォルトのまま） |

### 3-2. SSL（HTTPS）化の確認
1. インストール完了後、**30分〜1時間程度待機**する。
2. **[サイト管理]** > **[サイトセキュリティ]** > **[無料独自SSL]** が **「利用中」** になっていることを確認する。

> **💡 【補足】SSL待機の重要性**
> Let's Encrypt等の無料SSL証明書が発行・適用されるまでにタイムラグがある。この完了前にWordPressの内部設定（URL設定など）を触ると、リダイレクトループなどの不具合を引き起こす原因となるため、必ず「利用中」を確認してから次へ進む。

## 4. WordPress 初期設定・基盤構築手順

ここからの作業はWordPress管理画面（ `https://seal-search.com/wp-admin` ）にて行う。

### 4-1. パーマリンク設定（最重要）

1. 左メニュー **[設定]** > **[パーマリンク]** をクリック。
2. 共通設定で **「投稿名」** （`/%postname%/`）を選択し、**[変更を保存]**。

> **💡 【補足】パーマリンクを「投稿名」にする理由**
> GoogleのSEOガイドラインにおいて、URLは「シンプルで論理的、かつ人間が理解できる単語」が推奨されているため。日付ベースやIDベース（`?p=123`）を避け、記事ごとに `bonbondrop-osaka-umeda` のようなURLを手動設定できるようにする。

### 4-2. テーマのインストール

1. 左メニュー **[外観]** > **[テーマ]** > **[新規追加]** をクリック。
2. 事前購入・ダウンロード済みのテーマ（SWELL等）のzipファイルをアップロードし、**[有効化]** をクリック。

## 5. データベース（機能）実装手順（シールマニアでは現状未実装）

本システムのコアとなる「在庫管理データベース化」を行う。

### 5-1. 必須プラグインの導入

**[プラグイン]** > **[新規追加]** から以下をインストールし、有効化する。

* **システム構築系:**
* Advanced Custom Fields (ACF)
* Category Order and Taxonomy Terms Order
* Admin Columns (Pro版推奨：管理画面一覧から直接データ編集するため)


* **SEO・セキュリティ系:**
* SEO SIMPLE PACK (※SWELL利用時のみ。Cocoonの場合は不要)
* XML Sitemaps
* Wordfence Security
* SiteGuard WP Plugin



### 5-2. 情報設計（カテゴリー作成）

**[投稿]** > **[カテゴリー]** から、以下のツリー構造を作成する。

1. **商品シリーズ** (親) -> ボンボンドロップ (子), にじいろポッケ (子)
2. **都道府県** (親) -> 北海道 (子), 東京都 (子), 大阪府 (子)...
3. **店舗系列** (親) -> イオン (子), ロフト (子)...

### 5-3. カスタムフィールド（ACF）の設定【システム中核】

1. **[ACF]** > **[フィールドグループ]** > **[新規追加]**。
2. グループ名を **「店舗・在庫情報」** とする。
3. 以下の通りフィールドを厳密に設定する。

| フィールドラベル | フィールド名 (`name`) | フィールドタイプ | 必須設定 | 備考・選択肢の記述内容 |
| --- | --- | --- | --- | --- |
| 店舗名 | `store_name` | テキスト | 必須 |  |
| 在庫状況 | `stock_status` | 選択肢 | 必須 | `◎ : 在庫あり（余裕）`<br>

<br>`◯ : 在庫あり`<br>

<br>`△ : 残りわずか`<br>

<br>`× : 在庫なし`<br>

<br>`？ : 目撃情報あり` |
| 確認日時 | `check_date` | 日時 | 必須 | カレンダーUIで選択可能にする |
| 情報ソース | `source_url` | URL | 任意 | 公式HPやXのURL |
| 備考・メモ | `memo` | テキストエリア | 任意 | 「レジ横」「お一人様1個」等 |

4. **[設定]** (Location Rules) で、「投稿カテゴリー」が「すべてのカテゴリー（または対象カテゴリー）」に等しい状態にし、**[変更を保存]**。

> **💡 【補足】ACFによるデータベース化の選定理由**
> WordPressの標準機能である「本文エディタ」に直接在庫状況を書き込むと、将来的に「在庫ありの店舗だけを絞り込み検索する（Search & Filter Pro等を使用）」といったWebアプリ的な挙動が不可能になる。
> データを「メタデータ（カスタムフィールド）」として独立したカラムに持たせることで、RDB（リレーショナルデータベース）と同様の検索性・ソート性を担保する。

### 5-4. 運用オペレーションの最適化（Admin Columns設定）

1. **[設定]** > **[Admin Columns]** を開く。
2. 「投稿」のリスト画面に表示する項目を編集し、「作成者」や「コメント」等の不要な列を削除。
3. 手順5-3で作った「在庫状況」「確認日時」の列を追加し、**[インライン編集]をON**にする（※Pro版機能）。

> **💡 【補足】Admin Columnsの選定理由**
> 1人運営において、更新の手間は最大のボトルネック（技術的負債）となる。各店舗の在庫状況を変えるために「記事編集画面を開く→ステータスを変える→更新ボタンを押す」という画面遷移を数十店舗分行うのは現実的ではない。
> 一覧画面上でExcelのように直接ステータスを書き換えられるUIを構築することで、移動中などのスキマ時間にスマホから数分で全国の在庫更新を可能にする。
