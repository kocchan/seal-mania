# 「シールマニア」ビジネスプラン

## 1. 事業概要

**シール交換ブーム（特に「ボンボンドロップ」等）における、販売・入荷情報の集約プラットフォーム。**

実店舗・通販の公式情報に加え、SNS上の目撃情報を「都道府県別・商品別」に構造化して提供する。情報の「速報性（フロー）」だけでなく、蓄積データに基づく「傾向分析（ストック）」を強みとし、ユーザーの購買行動を支援するWebメディアである。


## 2. 事業目的（Mission）
### 外向き（ユーザー価値）
* **「今どこで買えるのか」の可視化**
* 分散する情報を集約し、最も分かりやすい情報ハブとなる。

* **保護者・ライト層の負担軽減**
* 常にSNSを監視しなくても、安心して購入判断ができる環境を提供する。

### 内向き（運営方針）
* **再現性のある「副業Webメディアモデル」の構築**
* 低コスト、1人運営、半自動化で回る仕組みを作る。

* **将来的な横展開**
* 他のシール、カプセルトイ、コレクション商材へ即座に展開可能な基盤（システム・ノウハウ）を確立する。



---

## 3. 提供価値（Value Proposition）

### 3.1 全体定義

単なる「情報の羅列」ではなく、**ユーザーの「意思決定（買いに行く／待つ／通販で買う／諦める）」を支援する判断材料**を提供する。

### 3.2 ユーザー状態別の解決策

| ユーザーの状態 | Before（課題） | After（提供価値） |
| --- | --- | --- |
| **探している** | SNSを遡るのが手間、情報の新旧が不明。 | 最新情報が1ヶ所に集約。発生日時が明確で**「探す時間」そのものを大幅削減**。 |
| **迷っている** | 行って売っていないリスク、どこが狙い目か不明。 | 地域・店舗の入荷傾向（ストック情報）から、**「不確実性」を下げて行動できる**。 |
| **初めて触れる** | 何が流行りか、どこで買うのが普通か不明。 | シリーズ一覧・定価・販売場所の基本情報があり、**参入ハードルが下がる**。 |

### 3.3 情報整理の価値

* **時系列の整理:** いつ入荷したか明確で、古い情報に惑わされない。
* **地域の整理:** 都道府県・エリア単位で絞り込め、自分に関係ある情報へ即座にアクセスできる。
* **商品の整理:** シリーズ単位で俯瞰でき、再入荷の傾向やサイクルが掴める。

### 3.4 信頼性と安心感の担保

* **情報のステータス化:** 「公式発表」「目撃情報」「未確認（噂）」を明確に区別する。
* **断定しない誠実さ:** 「絶対に売っている」ではなく**「◯月◯日時点で目撃情報あり」**というファクトベースのスタンスを貫き、ユーザーの誤情報による空振り（失敗体験）を防ぐ。

## 4. マネタイズ

1人運営の副業モデルとして、以下のキャッシュポイントを設計する。
1. **成果報酬型広告（アフィリエイト）**
* **ECサイト誘導:** プレミアム価格になりがちな商品を「定価で買えるタイミング」や「Amazon・楽天の在庫復活」と同時にリンクを流し、物販アフィリエイトで収益化する。
* **関連商材の紹介:** シールを収納する「バインダー」「スリーブ」などの周辺アイテムの記事を作成し、あわせて購入を促す。

2. **クリック報酬型広告（Google AdSense）**
* アクセス（PV）に比例して収益が発生するモデル。在庫検索という「何度も訪れる（回遊性の高い）」サイトの性質と非常に相性が良い。
